# ColorFlow 技术栈开发文档

> **版本**：v0.1 | 日期：2026-05-09 | 状态：规划中  
> **技术栈**：Python 3.12 + FastAPI + VTracer + Docker  
> **架构**：三层解耦（接口层 → 封装层 → 引擎层）

---

## 一、技术选型

### 1.1 核心技术栈

| 层级 | 技术选型 | 版本 | 选择理由 |
|------|---------|------|---------|
| **执行引擎** | VTracer | latest | Rust 实现，性能最优，Python 直接调用 |
| **SDK 封装** | Python | 3.12 | AI 生态主流语言，VTracer 官方支持 |
| **API 服务** | FastAPI | ≥ 0.109 | 异步高性能，自动 OpenAPI 文档 |
| **Web 服务器** | Uvicorn | ≥ 0.27 | ASGI 标准实现，生产可用 |
| **参数校验** | Pydantic | ≥ 2.0 | 类型安全，FastAPI 原生集成 |
| **HTTP 客户端** | httpx | ≥ 0.25 | 异步 HTTP，支持连接池 |
| **CLI 封装** | Bash + Docker | - | 零依赖分发，跨平台 |
| **容器化** | Docker | 20.10+ | 一键部署，环境隔离 |

### 1.2 技术选型依据

#### 为什么选 VTracer？
- Rust 实现，同类工具中性能最优
- Python 直接 import，无需网络调用
- 支持 color/grey/human 三种模式，覆盖主流场景
- 已有成熟社区，维护活跃

#### 为什么选 FastAPI 而非 Flask/Django？
- **性能**：异步架构，QPS 是 Flask 的 3-5 倍
- **类型安全**：Pydantic 原生集成，参数校验零额外代码
- **自动文档**：Swagger UI / ReDoc 开箱即用
- **现代化**：类型提示完整，IDE 支持好

#### 为什么选 httpx 而非 requests？
- httpx 支持异步，FastAPI 异步性能不被阻塞
- 兼容同步模式，平滑迁移
- 未来扩展 WebSocket 更方便

## 三、模块设计

### 3.1 SDK 模块（colorflow_sdk/sdk.py）

```python
import vtracer
import os
from uuid import uuid4
from .exceptions import ColorFlowError, ValidationError, TraceError

class ColorFlowSDK:
    """
    ColorFlow Python SDK
    供 AI Agent 直接调用，将位图转换为 SVG
    """

    def __init__(self, output_dir: str = "/tmp"):
        self.output_dir = output_dir
        self._validate_output_dir()

    def _validate_output_dir(self):
        """确保输出目录存在"""
        os.makedirs(self.output_dir, exist_ok=True)

    def trace(
        self,
        image_path: str,
        mode: str = "color",
        colormode: str = "rgb8",
        hierarchical: str = "stacked",
        filter_speckle: int = 4,
        color_precision: int = 6,
        layer_difference: int = 64,
        corner_threshold: int = 60,
        length_threshold: float = 2.0,
        path_precision: int = 7,
    ) -> str:
        """
        将位图转为 SVG（落盘模式）

        Args:
            image_path: 输入图片路径（PNG/JPG/WebP）
            mode: color | grey | human
            filter_speckle: 斑点过滤阈值（1-100）
            ...

        Returns:
            输出 SVG 文件路径

        Raises:
            ValidationError: 参数校验失败
            TraceError: VTracer 执行失败
        """
        # 参数校验
        self._validate_path(image_path)
        self._validate_mode(mode)
        self._validate_range("filter_speckle", filter_speckle, 1, 100)
        ...

        # 生成输出路径
        output_filename = f"colorflow_{uuid4()}.svg"
        output_path = os.path.join(self.output_dir, output_filename)

        # 调用 VTracer
        vtracer.convert_image_to_svg_py(
            image_path=image_path,
            out_path=output_path,
            colormode=colormode,
            hierarchical=hierarchical,
            mode=mode,
            filter_speckle=filter_speckle,
            color_precision=color_precision,
            layer_difference=layer_difference,
            corner_threshold=corner_threshold,
            length_threshold=length_threshold,
            max_iterations=10,
            splice_threshold=45,
            path_precision=path_precision,
        )

        # 校验输出
        if not os.path.exists(output_path):
            raise TraceError("VTracer execution failed: output file not created")

        return output_path

    def trace_bytes(
        self,
        image_bytes: bytes,
        image_format: str = "png",
        **kwargs
    ) -> bytes:
        """
        将位图转为 SVG（内存模式，不落盘）

        Args:
            image_bytes: 图片字节数据
            image_format: 图片格式（png/jpg/webp）
            **kwargs: 同 trace() 的参数

        Returns:
            SVG 文件字节数据
        """
        import tempfile
        with tempfile.NamedTemporaryFile(suffix=f".{image_format}", delete=False) as tmp:
            tmp.write(image_bytes)
            tmp_path = tmp.name

        try:
            svg_path = self.trace(tmp_path, **kwargs)
            with open(svg_path, "rb") as f:
                return f.read()
        finally:
            os.unlink(tmp_path)
```

### 3.2 API 模块（api/routes/trace.py）

```python
from fastapi import APIRouter, File, Form, UploadFile, HTTPException, Header
from fastapi.responses import Response
from typing import Optional
from colorflow_sdk import ColorFlowSDK
from colorflow_sdk.exceptions import ValidationError, TraceError

router = APIRouter()

@router.post("/trace")
async def trace_image(
    image: UploadFile = File(...),
    mode: str = Form("color"),
    filter_speckle: int = Form(4),
    # ... 其他参数
    x_api_key: Optional[str] = Header(None),
):
    """
    将上传的图片转换为 SVG 矢量格式

    - **image**: 图片文件（PNG/JPG/WebP）
    - **mode**: 描图模式（color/grey/human）
    - **filter_speckle**: 斑点过滤阈值
    """

    # 校验文件格式
    allowed_types = ["image/png", "image/jpeg", "image/webp"]
    if image.content_type not in allowed_types:
        raise HTTPException(status_code=400, detail=f"Unsupported file type: {image.content_type}")

    # 读取图片内容
    image_bytes = await image.read()

    # 调用 SDK
    sdk = ColorFlowSDK()
    try:
        svg_bytes = sdk.trace_bytes(image_bytes, image_format=image.format, mode=mode, filter_speckle=filter_speckle)
    except ValidationError as e:
        raise HTTPException(status_code=400, detail=str(e))
    except TraceError as e:
        raise HTTPException(status_code=500, detail=str(e))

    return Response(content=svg_bytes, media_type="image/svg+xml")
```

### 3.3 认证中间件（api/middleware/auth.py）

```python
from fastapi import Request, HTTPException
from starlette.middleware.base import BaseHTTPMiddleware
import os

VTRACER_API_KEY = os.getenv("COLORFLOW_API_KEY", "mv-p4ss-k3y-2026")

class AuthMiddleware(BaseHTTPMiddleware):
    """API KEY 认证中间件"""

    async def dispatch(self, request: Request, call_next):
        if request.url.path.startswith("/api/"):
            api_key = request.headers.get("x-api-key")
            if api_key != VTRACER_API_KEY:
                raise HTTPException(status_code=401, detail="Invalid or missing API key")

        response = await call_next(request)
        return response
```

### 3.4 CLI 模块（cli/main.py）

```python
import argparse
import sys
from colorflow_sdk import ColorFlowSDK
from colorflow_sdk.exceptions import ColorFlowError

def main():
    parser = argparse.ArgumentParser(description="ColorFlow CLI - AI 矢量描图工具")
    parser.add_argument("--input", "-i", required=True, help="输入图片路径")
    parser.add_argument("--output", "-o", required=True, help="输出 SVG 路径")
    parser.add_argument("--mode", default="color", choices=["color", "grey", "human"])
    parser.add_argument("--filter-speckle", type=int, default=4)
    # ... 其他参数

    args = parser.parse_args()

    try:
        sdk = ColorFlowSDK()
        svg_path = sdk.trace(args.input, mode=args.mode, filter_speckle=args.filter_speckle)
        print(f"✓ SVG 已保存至: {svg_path}")
    except ColorFlowError as e:
        print(f"✗ 错误: {e}", file=sys.stderr)
        sys.exit(1)

if __name__ == "__main__":
    main()
```

```python
import logging

logging.basicConfig(
    level=logging.INFO,
```

### 9.2 结构化日志（JSON）

```python
import json
import logging

class JSONFormatter(logging.Formatter):
    def format(self, record):
        log_obj = {
            "timestamp": self.formatTime(record),
            "level": record.levelname,
            "logger": record.name,
            "message": record.getMessage(),
        }
        if record.exc_info:
            log_obj["exception"] = self.formatException(record.exc_info)
        return json.dumps(log_obj)

# 生产环境使用
logging.getLogger("colorflow").handlers[0].setFormatter(JSONFormatter())
```
