# ColorFlow × image2prompt 工作流集成方案

> 版本：v0.1 | 日期：2026-05-09 | 状态：规划中

---

## 一、背景与目标

现有工具矩阵：

| 工具 | 能力 | 输入 | 输出 |
|------|------|------|------|
| **image2prompt** | 图 → AI 提示词 | 位图 | 英文/中文提示词 + JSON |
| **ColorFlow SDK** | 位图 → SVG 矢量 | PNG/JPG | SVG 矢量文件 |
| **mcp-print** | Pantone 色彩 + 印刷报价 | HEX/CMYK | Pantone 匹配 + ΔE + 报价 |

**目标**：三者串联，构建完整的"图片 → AI 生成 → 矢量描图 → 色彩标准化 → 印刷落地"闭环。

---

## 二、核心应用场景

### 场景 A：AI 包装效果图生成闭环

```
用户上传参考图
     ↓
image2prompt → 生成 AI 绘画提示词（英文）
     ↓
Midjourney/SD → 生成高清包装效果图
     ↓
ColorFlow → 将效果图转为 SVG 矢量路径
     ↓
mcp-print → SVG 填充色 → Pantone 匹配 + ΔE + 油墨成本
     ↓
交付：SVG + Pantone 色号 + 报价单
```

**适用**：包装设计、品牌视觉物料

---

### 场景 B：AI 设计 → 色彩管理 → 生产落地

```
AI 生成设计图（Midjourney / DALL·E / SD）
     ↓
场景 A 完整链路
     ↓
输出三件套：
  1. SVG 矢量文件（可编辑、可缩放）
  2. Pantone 色号报告（主色 + 辅色 + ΔE 偏差）
  3. 印刷报价单（油墨 + 版材 + 调机 + 印刷）
     ↓
设计师 → 调色对色 → 客户确认
     ↓
直接发给印刷厂（附带色号）
```

**适用**：品牌设计、标签印刷、包装生产

## 三、集成方案设计

### 方案 A：独立工具串联（轻量级，零开发）

**适合**：设计师日常使用，无需编程

| 步骤 | 工具 | 操作 | 产出 |
|------|------|------|------|
| 1 | image2prompt（浏览器扩展）| 上传图片 → 生成 prompt | 英文 prompt 文本 |
| 2 | Midjourney/SD | 粘贴 prompt → 生成高清图 | AI 设计图 |
| 3 | ColorFlow SDK（CLI）| `colorflow -i output.png -o result.svg --mode color` | SVG 文件 |
| 4 | mcp-print | 提取 SVG 中的 HEX 色值 → 查 Pantone + 报价 | 色号 + 报价单 |

**工具间数据流动**：
```
image2prompt prompt 文本 → 手动复制到 MJ/SD
AI 生成图片 → 保存到本地 → ColorFlow CLI
ColorFlow SVG → 打开文件 → 手动提取 HEX → mcp-print 查色
```

**评价**：轻量但割裂，适合个人探索，不适合规模化生产。

---

### 方案 B：ColorFlow Web 集成（推荐，MVP）

在现有 ColorFlow Web（Flask 单页应用）上新增 image2prompt 功能 Tab。

```
┌─────────────────────────────────────────────┐
│           ColorFlow Web 增强版               │
│                                             │
│  Tab 1: 矢量描图    ← 已有                  │
│  Tab 2: Pantone 查色 ← 已有                 │
│  Tab 3: 色彩匹配     ← 已有                 │
│  Tab 4: 印刷报价     ← 已有                 │
│  Tab 5: AI 提示词生成 ← 新增（集成 image2prompt API）│
└─────────────────────────────────────────────┘
```

**新增 Tab 5 功能**：

| 功能 | 实现方式 | 说明 |
|------|---------|------|
| 图片 → prompt | 调用 OpenAI Vision API / Claude Vision | 传入图片 → 返回描述 prompt |
| prompt 优化 | 调用 GPT-4o-mini | 优化为 Midjourney/SD 风格提示词 |
| SVG 色值提取 | Python 解析 SVG fill 属性 | SVG 中提取所有 HEX 颜色 |
| Pantone 自动匹配 | 调用 mcp-print pantone_search | HEX → 最近 Pantone + ΔE |

**架构图**：

```
┌─────────────────────────────────────────────────────┐
│                    ColorFlow Web                     │
│                                                      │
│  [图片]  ──→  [Vision API]  ──→  [prompt]           │
│                              ↓                        │
│                       [SVG 矢量]  ←  [ColorFlow SDK] │
│                              ↓                        │
│                    [SVG 色值提取]                     │
│                              ↓                        │
│  [prompt] + [Pantone 报告] + [SVG]  ←  输出三件套    │
└─────────────────────────────────────────────────────┘
```

**技术实现**：

```python
# /api/prompt/generate - 新增接口
@app.route("/api/prompt/generate", methods=["POST"])
def generate_prompt():
    """图片 → AI 描述 prompt（Vision API）"""
    image_bytes = request.files["image"].read()
    
    # 用 OpenAI Vision API 生成描述
    response = openai.ChatCompletion.create(
        model="gpt-4o",
        messages=[{
            "role": "user",
            "content": [
                {"type": "image", "data": base64.b64encode(image_bytes).decode()},
                {"type": "text", "text": "描述这张图片，详细到可以用作 AI 绘画 prompt"}
            ]
        }]
    )
    return jsonify({"prompt": response["choices"][0]["message"]["content"]})


# /api/svg/colors - 新增接口
@app.route("/api/svg/colors", methods=["POST"])
def extract_svg_colors():
    """SVG 文件 → 提取所有填充色 HEX"""
    svg_bytes = request.files["svg"].read()
    from xml.etree import ElementTree as ET
    
    tree = ET.fromstring(svg_bytes)
    ns = {"svg": "http://www.w3.org/2000/svg"}
    
    hex_colors = set()
    for elem in tree.iter():
        fill = elem.get("fill", "")
        if fill and fill.startswith("#"):
            hex_colors.add(fill.upper())
    
    return jsonify({"colors": list(hex_colors)})
```

### 方案 C：ColorFlow CLI 增强（命令行友好）

```bash
# 一条命令完成完整流程
colorflow-flow \
  --input design.png \
  --output ./output/ \
  --mode color \
  --match-pantone \
  --print-quote \
  --prompt-model gpt-4o

# 产出：
# output/design.svg         - 矢量图
# output/pantone-report.json - 色号报告
# output/print-quote.json   - 印刷报价
# output/prompt.txt         - AI 描述 prompt
```

## 四、功能优先级

| 优先级 | 功能 | 说明 | 工作量 |

| **P2** | CLI flow 串联 | 一条命令完成全流程 | 1 人天 |

## 五、与现有系统的关系

```
ColorFlow SDK（矢量描图）
       ↑
ColorFlow Web（4 Tab → 5 Tab 增强）
       ↑
mcp-print（色彩管理）
       ↓
image2prompt（prompt 生成）
       ↓
Midjourney / Stable Diffusion（AI 生成图片）
       ↓
ColorFlow（描图）→ 循环
```

**核心数据流**：
```
HEX 色值（SVG）
    ↓
mcp-print.pantone_search() → Pantone 匹配 + ΔE
    ↓
print_cost_estimate() → 印刷报价
    ↓
输出：色号报告 + 报价单
```
